# Work order 03 - window frame + tiling layouts (layout mock)
Read `orders/STYLE.md` first (all of it). Build ONE file: `components/ds-window.html`. Slug for shots: `03`.

Shows the generic app window and how windows tile on the side monitor. The content inside the windows is NOT the
point - keep it simple placeholders (see below) so the frames and gaps read.

States (pick with `?state=`; default = `stack`):
- `float`: two floating windows on the `.stage`: one focused (`.win.focus`, ~1100x680, front) overlapping one
  unfocused (`.win.blur`, ~800x520, behind, offset up-left). Show the frame details: title with app name + context
  (`KITTY · ~/src/clockmost-desktop`, `DOLPHIN · HOME`), the three buttons, hairline under the bar.
- `halves`: two windows side by side, each half the screen (8px gaps/edges).
- `stack`: left half one window; right half two windows stacked (the "1 + 2" layout Mario uses most).
- `quad`: 2x2 grid.
- `full`: one maximized window (`.win.max`), its title bar on top.
- `snap`: the `halves` desktop but showing the snap ZONE preview while dragging a window: the target half drawn as
  a translucent yellow-edged area (1px yellow border at 60% opacity, very light yellow fill ~6%, `.micro` label
  `SNAP · LEFT HALF` in the centre) with the dragged window drawn smaller at 70% opacity under the cursor area.
- In every tiled state exactly ONE window is focused (yellow title block), the others `.blur`.

Placeholder content per window (static, simple, but believable at a glance):
- Kitty: dark body, 8-10 lines of mono text (a fish prompt `benylin@clockmost ~/src/clockmost-desktop (main)>`,
  `git status` output in muted colours, a yellow block cursor).
- Dolphin: a left sidebar strip (Places list: Home, Desktop, Documents, Downloads, .config, Drives/Data) and a main
  area with 10 file rows (name, size, date) - plain, no icons needed.
- Phonograph mini: a 3-row track list (title + artist + time), first row highlighted lavender (`rgba(207,198,244,.12)`).
- Discord mini: 5 chat lines (name in colour + text).
Distribute: `stack` = Kitty left, Dolphin top-right, Discord bottom-right. `quad` = all four. `halves` = Kitty +
Dolphin. `full` = Dolphin. `float` = Kitty (focus) over Dolphin.

A tiny state switcher is allowed: a row of plain text links at the bottom-left over the stage (`.micro`, links to
`?state=...`), outside the windows. Check: screenshot EVERY state (`kit/shot.sh "components/ds-window.html?state=quad"
out/shots/03-quad.png 2000` etc.) and look at each. Report to `orders/03-report.md`.
