# Work order 08 - Dolphin file manager (layout mock)
Read `orders/STYLE.md` first (all of it). Build ONE file: `components/ds-dolphin.html`. Slug for shots: `08`.
Dolphin maximized on `.stage.plain` (`.win.max`, full screen). Mario's wishes: Windows-Explorer-like - "the side bar,
the pins and the folder tree"; hidden files always shown; `~/.config` pinned; data disks mounted under
`~/Drives/<name>` so drives and folders live in ONE tree.
- Top row (56px, hairline under): back / forward / up line icons, then the path as a breadcrumb of segments
  (`HOME` › `src` › `clockmost-desktop`) - each segment a flat chip, the last one `--ink`, separators `›` dim - then
  view-mode buttons (icons / details (active, yellow icon) / tree), a `.field.sm` search 280px, then window buttons.
  Title `DOLPHIN` sits at the far left before the nav icons.
- Left sidebar 280px (`--side`): section `.label` `PINS`: Home, Desktop, Documents, Downloads, `.config` (pinned,
  small pin glyph), Pictures; section `TREE`: an indented folder tree rooted at Home with disclosure triangles:
  `benylin` > `Drives` > `Data` (drive glyph), `Games` (drive glyph); `src` (expanded) > `clockmost-desktop`
  (current = yellow block `.sel`), `felt`; `.config` (collapsed); `Downloads`. Section `DEVICES`: `Data · 1.8 TB`,
  `Games · 920 GB` each with a thin usage bar (fill `--ink2`, one at 82% shows the bar crimson).
- Main area: DETAILS view. Column header row (`.label` style): NAME, SIZE, MODIFIED, TYPE with a small sort arrow on
  MODIFIED. ~18 rows, 32px each, alternating very faint stripes: folders first (`.git`, `design`, `install`,
  `packages`, `scripts`) then files (`.gitignore`, `README.md`, `TODO.md`, `install.sh`, `packages.txt`,
  `wallpaper.png` ...); hidden ones dimmer; a folder glyph or file glyph per row (simple line icons). Two rows are
  SELECTED (yellow left edge 3px + slightly lighter row, not a full yellow block - multi-select).
- Right: an info panel 300px (`.panel` look): a big file-type glyph, `README.md`, then rows `SIZE 7.0 KB`,
  `MODIFIED 2026-10-10 01:09`, `TYPE MARKDOWN`, `OWNER BENYLIN`, a barcode + micro code.
- Bottom status bar (32px, hairline above): `5 FOLDERS · 13 FILES · 2 SELECTED (11.4 KB)` left in `.micro`/`.label`;
  right: `1.2 TB FREE` + a zoom `.sld` 120px.
