Read `orders/STYLE.md` first (all of it). Build ONE file: `components/ds-firefox.html`. Slug for shots: `06`.
Firefox fullscreen on the main monitor: `.stage.plain` + a `.win.max` filling 1920x1080. Mario used Zen browser for
a long time: vertical tabs on the left, a clean top. Style like the phonograph/chat (same chrome language).

Layout:
- Left sidebar, 272px, `--side` background:
  - top: the Firefox logo (`firefox.svg`, 22px) + `.wtitle` `FIREFOX` + `.micro` `157.0 · PROFILE BENYLIN`.
  - pinned tabs: a 4-column grid of 48px square tiles with letter/glyph favicons (Gitea `G`, Plane `P`, Zabbix
    `Z`, YouTube `▶`), 6px corners, dark field background.
  - a `.label` `SPACE · CLOCKMOST` with a small chip row switching spaces (`CLOCKMOST` active yellow, `PERSONAL`,
    `GAMES`).
  - the tab list: 9 tabs, each row 36px: 16px favicon box + title (body font, ellipsis) ; the ACTIVE tab = yellow
    block `.sel` (like the chat's active channel); one tab has a crimson `.tag` `REC` (playing audio) and one shows a
    small orange `.notif`. Two tabs are inside a TAB GROUP: a group header row `FELT` in a small violet chip with the
    two tabs indented under it with a thin violet left line.
  - bottom: `+ NEW TAB` row (plus = the X rotated), then micro `9 TABS · 2 GROUPS`.
- Top row (to the right of the sidebar), 56px, hairline under: back / forward / reload line icons (28px `.wb`
  style buttons without borders), then the URL field centred (`.field`, 760px, showing a small lock glyph +
  `git.clockmost.com/Benylin/clockmost-desktop`, the host part `--ink`, the path `--dim`), then 3 extension
  buttons (uBlock shield, KeePassXC key, Vencord-free - just 3 line icons), then the window buttons.
- Content area: a believable dark web page - the Gitea repo page of `Benylin/clockmost-desktop`: repo header
  (name, `Private` chip, star/watch counters), a file table (folders `design`, `install`, `packages`, files
  `README.md`, `TODO.md` with last commit messages + dates), a README preview below with a heading and two
  paragraphs. Keep it plain - it is a WEBSITE inside the browser, not Endfield-styled: use neutral greys and the
  site's own simple look, so the browser chrome around it is what reads as Endfield.
- Bottom-right of the content: a small Firefox download panel popup (`.panel`, 320px): `.label` `DOWNLOADS`, 2
  rows: `clockmost-desktop-recipe.tar.zst · 18.2 MB · DONE` (green check), `cachyos-260809.iso · 2.9 GB · 64%` with a
  thin progress bar (yellow fill).
