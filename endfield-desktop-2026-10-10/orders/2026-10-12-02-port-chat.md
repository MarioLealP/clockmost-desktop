## How
1. `chat.css`: all the page's CSS scoped under the root class `.ef-chat`. Page-level backgrounds on html/body and
   `position: fixed` become absolute layers inside the root (phonograph.css shows how, including the
   `will-change: transform` note on those layers that keeps text anti-aliasing identical). The background image
   is already at `src/assets/topo-floor-strip.svg` - use `url(../assets/topo-floor-strip.svg)`. Keep every value.
2. `chat.js`: `EF.chat(opts) -> el`, an IIFE like phonograph.js. Builds the same DOM; the page's current data
   (servers, channels, messages, user) becomes the default for opts. Methods: `el.enter()`, `el.selectChannel(i)`
   (same as clicking the i-th `.ch` row), `el.toggleReaction(i)` (same as clicking the i-th `.chip`),
   `el.leave()` (fade in place, rule 15: opacity only, nothing moves), `el.destroy()` (stops the diamond pulse
   rAF loop, drops listeners). Query inside the root only, no ids that would clash with a second instance.
   Use `EF.SNAP`, `EF.SETTLE`, `EF.SLOW` from core.js; a small local `wait()`/tween adapter is fine (see phonograph.js).
3. `chat.html`: preview page like `src/apps/phonograph.html`; mounts one instance, calls `el.enter()`, exposes
   `window.chat`.
