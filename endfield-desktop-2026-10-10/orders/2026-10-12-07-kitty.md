# Work order 07 - Kitty terminal (layout mock)
Read `orders/STYLE.md` first (all of it). Build ONE file: `components/ds-kitty.html`. Slug for shots: `07`.
Kitty is Mario's terminal (fish shell). On `.stage`: one large focused Kitty window (`.win.focus`, ~1500x860,
centred) - the terminal theme is the point.
- Title bar: `.wtitle` `KITTY <span>· ~/src/clockmost-desktop</span>`, window buttons.
- Kitty's own tab bar directly under the title bar (34px, `--rail` background): 3 tabs as flat segments
  `1 FISH`, `2 SSH CLOCKMOST-ADMIN`, `3 BTOP`; the active tab = yellow block with dark text; inactive dim; a tiny
  orange `.notif` on tab 2 (activity). Right end: `.micro` `KITTY 0.49 · 3 TABS`.
- Terminal body: background `#0d0d0e`, padding 18px 22px, font var(--mono) 15px, line-height 1.5. Define and USE an
  Endfield 16-colour ANSI palette (write it as CSS variables in the page): black `#0d0d0e`, red `#d91e36`,
  green `#7ddb57`, yellow `#FFFA00`, blue `#5aa7ff`, magenta `#ff1aac`, cyan `#3FD0E8`, white `#c9ccd3`, and
  brighter variants. Content (realistic, ~30 lines):
  - a fish prompt in two parts: `benylin@clockmost-desktop` (cyan) ` ~/src/clockmost-desktop` (ink) ` main` (yellow,
    git branch) `>` ; prompt lines are separated by an empty line.
  - `git status` output (branch line, 2 modified files in red, 1 untracked in red, hint lines dim).
  - `ls -la` style coloured listing (dirs blue, executables green, hidden files dim).
  - `paru -Syu` excerpt: `:: Synchronizing package databases...`, 3 upgrade lines with old -> new versions.
  - the last prompt with a yellow BLOCK cursor (no blinking).
- A right-side scrollbar hint: 3px wide thumb, faint.
- Below the window, outside it, on the stage: a palette legend strip - 16 small square swatches with their hex in
  `.micro` under each, label `.label` `ENDFIELD ANSI 16`. (It documents the theme for the real build.)
