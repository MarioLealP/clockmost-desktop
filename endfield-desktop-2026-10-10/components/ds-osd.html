PipeWire

PipeWire is a low-latency graph-based audio, video and device server for Linux. It routes sound between applications and hardware, covers the use cases of PulseAudio and JACK, and keeps per-application volume, capture and screen sharing in one place.

Configuration lives in ~/.config/pipewire. The session manager, WirePlumber, picks the devices and the graph connects them. Inspect the running graph with pw-top and list a node with pw-cli ls Node.

For the DT 880 on the USB DAC, set the sample rate to 96 kHz in the device profile and leave the quantum at 1024 for playback, 256 for the headset mic. Latency under 10 ms is comfortable for voice; music players do not need more than the defaults.

Volume handling replaces the PulseAudio layers: application streams show up as nodes with their own volumes, and the sink keeps the hardware mix. The shell volume keys talk to the default sink, so a per-application mixer is only needed when one app should be quieter than the rest.

Bluetooth headsets switch to the headset profile on capture, which drops the output sample rate. If the music keeps playing while the mic is open and sounds thin, that profile switch is the reason, not the player. WirePlumber's headset-separator policy keeps A2DP and HSP on separate nodes so the switch is visible in the graph before it happens.

Screen capture and window sharing go through the portal: the picker grants one source per request and the permission is not remembered unless the session says so. OBS, Spectacle and the browser share the same portal, so fixing one fixes all three.
